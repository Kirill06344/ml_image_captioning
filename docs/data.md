# Источники и подготовка данных

Задание: MS-COCO 2014, подмножество 5k изображений.

- Официальный корпус и загрузки: https://cocodataset.org/#download
- Формат COCO: https://cocodataset.org/#format-data
- API авторов: https://github.com/cocodataset/cocoapi
- Caption evaluation: https://github.com/tylin/coco-caption
- https://gymnasium.farama.org/ описывает API сред reinforcement learning, не датасет COCO.

Рабочее допущение реализации (обоснование — docs/experiment_protocol.md): 5000 уникальных изображений всего, из них 4000 из train2014 для train,
а 1000 из val2014 делятся на собственные val/test по 500. Это не Karpathy test 5k и не официальный
скрытый COCO test. Если в учебном задании подразумевалось другое, изменить до подготовки данных.

tools/prepare_data.py читает COCO captions JSON и локальные изображения. Ничего не скачивает.
Отбирает id детерминированно, сохраняет ВСЕ подписи каждого выбранного изображения,
проверяет непересечение сплитов и существование файлов. Копирует только выбранные изображения.
Нельзя превращать несколько подписей фотографии в независимые сплиты.
Лицензии аннотаций и самих изображений проверить отдельно до распространения производной копии.

Решение принято до подготовки реальных данных; соответствие замыслу преподавателя остаётся
допущением. Это не стандартный benchmark 5k test; показатели публикаций напрямую не сравниваются.
